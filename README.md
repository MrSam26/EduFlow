# EduFlow

Онлайн-дневник для планирования обучения. Учебный проект по дисциплине «Разработка веб-интерфейсов».

В ходе работы:
- созданы восемь связанных страниц по макетам из Figma;
- применена семантическая структура HTML;
- разработаны формы входа, регистрации и редактирования профиля;
- использованы различные CSS-селекторы и общий файл стилей.

## Запуск

Скачайте проект и откройте `index.html` в браузере. Страница входа находится в файле `login.html`.

## Технологии

HTML, CSS и JavaScript.

Проект представляет собой статическую учебную версию сайта.
